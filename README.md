# Liven Frontend

Aplicação web em React + Vite para o condomínio.

## Como rodar

```powershell
npm install
npm run dev
```

## Variáveis de ambiente

Crie um arquivo `.env.local` com:

```env
VITE_API_URL=http://localhost:8000/api/v1
```

## Observações

Este repositório contém apenas o frontend. O backend e a infraestrutura ficam em outro repositório.
